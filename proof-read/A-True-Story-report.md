## Notes on em-dash style

The working copy consistently renders the Atlantic Monthly's double-hyphen `--` as an em-dash `—`. This is a systematic typographic house-style decision (approximately 15+ instances). If the edition aims to match the 1874 Atlantic Monthly form, all should revert to `--`. If the house style is to use em-dashes, this can stand — but it should be a documented decision, not an inconsistency.
