# Mark Twain Reappears — OKF Bundle

This is an [Open Knowledge Format](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md) (OKF v0.1) bundle for the project hosted at **https://mark.otrobonita.com**.

It exists so that any AI agent (or person) visiting the site can read a structured, curated account of what the project is — without scraping a JavaScript-rendered chat app and guessing.

**Read [`reading-guide.md`](/reading-guide.md) first.** It explains the one thing that matters most here: which parts of this site are documented historical fact and which parts are the project's creative frame. An agent that skips it will either flatten the conceit or report that Mark Twain is literally alive. Neither is correct.
