# Project Gutenberg (canon)

The canonical English editions: the novels, the autobiography, the seven-volume Letters, the speeches, the essays. About **50 works, ~20 MB**. Built from a curated index page that organizes Twain's output into a clean bibliography; the same script also handles "subject" pages, which is how works *about* a person are found rather than works *by* them.
