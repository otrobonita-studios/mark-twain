# Site

The site is a JavaScript-rendered chat application. Its three sections:

- [About Me](/site/about.md) — `/about` — Twain's first-person introduction, in two registers.
- [The Diary](/site/diary.md) — `/diary` — dated entries; begins with the return.
- [The Library](/site/library.md) — `/complete-works` — the bibliographic archive.

The home page is a chat with [Mark Twain](/people/mark-twain.md), with visitor controls for answer length, tone, and language register.
