About Ox Alpha

OpenRouter makes Ox Alpha by Stealth available through a unified, OpenAI-compatible API using the model ID stealth/ox-alpha. It is served by Stealth.

Ox Alpha accepts text, images and video and returns text. It has a 1,048,576-token context window and a maximum output of 131,072 tokens.

It was released on August 20, 2026.
