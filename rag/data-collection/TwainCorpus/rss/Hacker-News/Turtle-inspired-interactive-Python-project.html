What you’ll do

Follow the steps below to build the project. You can write and check your code right in your browser.

  1. 1
    Welcome!
    Start a small visual project where Python movement calls create a web on the screen. You will import the spider helper and see each call change the preview.
    Up next
  2. 2
    What will we learn?
    Preview the Python building blocks that turn movement instructions into a spider web. You will use imports, function calls, arguments, strings, and code order.
  3. 3
    What are we building?
    See how a short Python file can move the spider and draw a square spiral web. The preview shows the kind of pattern you will build gradually.
  4. 4
    Import a module
    Use an import statement to make a module available, then access one of its items with dot notation. This lets a program reuse tools defined elsewhere.
  5. 5
    Prepare the spider•1 task
    Import the spider helper so its drawing tools are available. The preview will change from an empty grid to a spider ready at the center.
  6. 6
    Call a module function
    Call functions that belong to an imported module. Compare calls with no arguments and calls that receive a number.
  7. 7
    Move the spider forward•1 task
    Add one movement call so the spider leaves a visible line in the preview. This first strand starts the square spiral near the center.
  8. 8
    Run calls in order
    See how Python runs function calls from top to bottom. Rearrange a short sequence to change the output.
  9. 9
    Turn the spider•1 task
    Add a right-angle turn after the first strand so the square spiral can bend around the center. The next movement will use the new heading.
  10. 10
    Draw after the turn•1 task
    Add another movement after the turn so the output shows the first corner of the square spiral. This keeps the path small before it grows outward.
  11. 11
    Shape the square spiral•1 task
    Add more movement and turn calls until the drawing grows into a square spiral. Keep the shape as a direct sequence of calls for now.
  12. 12
    Pass text as an argument
    Pass quoted text to a function and see how a different string changes the function's output. Matching quotation marks tell Python where the text begins and ends.
  13. 13
    Pick a web color•1 task
    Add a color call so a later strand of the square spiral uses a different color. The color value is a string argument.
  14. 14
    What we learned
    Review how imports and function calls created the finished web drawing. Connect each Python idea to the visible result in the preview.
  15. 15
    Next steps
    Find natural ways to keep practicing after completing the drawing. Use the finished web as a starting point for small experiments.
