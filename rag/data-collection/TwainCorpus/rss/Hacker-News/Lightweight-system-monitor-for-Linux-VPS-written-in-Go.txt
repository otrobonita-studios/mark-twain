vpsmon

Lightweight system monitor for Linux VPS. Single Go binary, ~5MB RAM usage.

Monitors CPU, memory, swap, disk, network, uptime, and process count. Web UI with login, auto-refreshes every 5 seconds.

Installation

curl -sL https://raw.githubusercontent.com/leodeim/vpsmon/main/install.sh 
|
 sudo bash

Uninstallation

curl -sL https://raw.githubusercontent.com/leodeim/vpsmon/main/uninstall.sh 
|
 sudo bash
