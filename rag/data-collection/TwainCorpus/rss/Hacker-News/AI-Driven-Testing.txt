What it does
One primitive, three modes.
Everything in Deltix is built on a single thing: an AI agent attempting a user task. The three modes are the three ways you run it.
Task
Try once
“Can my user actually do this?”
Ad-hoc. You’re building a new flow and you want to know if it works for a real user, without scheduling a research session. Write the task, watch the agent try, read the screenshot of where it got stuck.
Playbook
Save and replay
“Did we break it?”
Take any successful run and save it as a Playbook. Replay it deterministically on every build, from the dashboard. Pass or fail in seconds.
Experiment
Compare two builds
“Which design wins?”
Run the same task against two builds of your app, side by side. See which one your users can complete and which one breaks, before the design debate goes to A/B testing in production.
How it fits
From discovery to regression.
Most testing tools force a choice. Deltix does both.
01
Explore
Describe a task in plain English. Deltix navigates your app like a first-time user, discovering, hesitating, succeeding, or getting stuck. Every step is captured.
02
Save
When a run completes the flow you wanted, save it. One click turns the successful path into a deterministic playbook. Same interactions, same targets, every time.
03
Replay
Replay the playbook from the dashboard against any new build. Same interactions, same checks. Pass or fail in seconds, with no flaky XCUITest assertions to maintain.
