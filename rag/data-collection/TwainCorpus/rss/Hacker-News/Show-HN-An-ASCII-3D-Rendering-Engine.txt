[ HOW IT WORKS ]

>

glyphcss loads OBJ, glTF, GLB, STL, and VOX mesh files. Each scene
              renders into a single 
<pre>
: the rasteriser
              projects every polygon, fills a 
cols × rows
 character
              grid, and writes one string to 
textContent
 per render.
              There are no per-polygon DOM nodes and no 
matrix3d
.

>

Interactivity is opt-in and sparse: drop a 
<GlyphHotspot>

at any 3D anchor and glyphcss emits one absolutely-positioned

<div>
 over the projected cell. Real DOM events,
              real 
:hover
 styles, real 
role="button"

accessibility — without one DOM node per polygon.
