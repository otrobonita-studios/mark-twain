Fedora 45 Atomic Desktops Look To Allow For Web-Based Remote Installations

Written by Michael Larabel in Fedora on 23 July 2026 at 09:52 AM EDT. Add A Comment
One of the latest change proposals filed for Fedora Linux 45 is for supporting web-based remote installations of Fedora Atomic Desktop images. The change still needs to be approved by the Fedora Engineering and Steering Committee (FESCo), but the plan is beginning with Fedora 45 to allow for the Anaconda WebUI to be supported for remote installations of Fedora Atomic Desktop images. The Fedora Anaconda WebUI itself has been in the works for a while and is now about it exposing it to the Fedora Atomic Desktop world as a new option for installs.

Those deploying Fedora Atomic Desktop to systems would be able to boot the system with the "inst.webui.remote" kernel parameter and then complete the OS installation from a web browser on another machine over HTTPS. For security is pin-based authentication support with the Anaconda WebUI. This change would benefit all Fedora Atomic Desktop images like Silverblue and Kinoite. Initially this web-based remote install support for Fedora Atomic Desktop images would be treated as a tech preview. Besides pin-based authentication, HTTPS is used for secure communication. Again, it would also be opt-in via the "inst.webui.remote" option at boot time. Those wishing to learn more about this Fedora 45 Atomic Desktop remote install proposal can find the planning details via the Fedora Wiki.
