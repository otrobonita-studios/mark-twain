Hand Wave

Sign recognition for web and iOS, backed by a small Python inference service.

Watch the demo on YouTube

Setup

Requirements: pnpm 10.33+, Node 22+, Python 3.11/3.12, uv, and moon.

cp .env.example .env
pnpm install
uv sync --project apps/inference

Don't forget to set 
VITE_INFERENCE_URL
 in 
.env
.

Development

pnpm dev
