First, ensure that the 
qtbase5-dev package
 is installed:

sudo
 apt
 update
 &&
 sudo
 apt
 install
 qtbase5-dev

Next, download the 
Epson Scan2 driver
. Once you have the file, unzip it, open the folder, right-click on the 
install.sh
 file, and 
Run as a Program
.

The Epson Perfection V39 II scanner is ready to use. To test the scanner, connect it and run the following
          command:

epsonscan2
 
These steps were tested on Ubuntu 26.04.
