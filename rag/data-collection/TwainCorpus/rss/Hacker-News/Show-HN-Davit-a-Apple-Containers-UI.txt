How is this different from Docker Desktop?

It's Apple's engine.
 Each container runs in its own lightweight VM via Apple's Virtualization framework â sub-second boots, per-container IP addresses, optimized for Apple silicon.

OCI all the way.

Nothing between you and the daemon.

FAQ

How much memory does it use?

The honest answer is architectural: there's 
no always-on multi-gigabyte Linux VM
. Docker Desktop keeps one big VM running whether or not you have containers; Apple's platform instead boots a 
separate lightweight VM per container
, sized to that container, and tears it down when the container stops. With nothing running, the platform's background services idle at roughly 
25 MB
. Davit itself is a native SwiftUI app (no Electron) â its footprint is mostly shared macOS framework memory. So the more containers you're 
not
 running, the less it costs you.

How does it compare to OrbStack?

OrbStack is a polished commercial app with its own Docker-compatible virtualization layer. Davit is free and open source, and is a UI on top of 
Apple's own container platform
 â so the engine is Apple's, not a third party's. Both run standard OCI images. If you specifically want Apple's Containerization stack (per-container VMs, Apple-silicon-native), Davit gives you a native front-end for it; if you want a drop-in Docker daemon replacement with broad tooling compatibility, OrbStack is the more mature choice today.
