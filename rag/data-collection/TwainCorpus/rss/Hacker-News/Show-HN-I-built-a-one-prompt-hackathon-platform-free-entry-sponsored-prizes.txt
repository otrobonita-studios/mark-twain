Under the hood
No black box. We run your prompt on our own server for one reason: so every entry is a provable single prompt and single model call, with no edits or retries. Your API key is encrypted, used for exactly one call, then destroyed, never stored with your entry. The result is published in a locked-down sandbox with a hash anyone can verify. Every entry is untrusted code, so it runs walled off and isolated: it can't reach our servers, your data, or any other entry.

Questions
Is it free to compete?
Yes. Entry is free and there is no fee to us, ever. The only cost is your own model run on your own API key (BYOK). Bring your best model and go. If you’d rather not pay for tokens, there are solid free options too. Meta’s
 
Muse Spark
 
gives every new account $20 in free credits, plenty for many one-shot runs on a strong frontier coding model (US-only for now). Anywhere else, use
 
Google Gemini
’s free tier, a frontier model too (rate-limited, but plenty for one shot a day). Or grab a free key from
 
Groq
 
or
 
NVIDIA
, which run open-source models, so tougher odds but a great prompt can still win.
Enter my API key? Are you CRAZY!?
Fair reaction. Here is the deal. Your key is encrypted the moment it arrives, used for exactly one model call, then permanently deleted. It is never stored in plain text, never written to logs, and never shown in any page or API response. Tip: create a fresh key with a spend limit and revoke it right after you submit.
Why run it on our side at all, instead of letting you paste in a result? Integrity. This is a 
one prompt
 challenge, so every entry has to be a provable single prompt and single model call, with no edits, retries, or chaining. Running it on our server with your key is what guarantees that, and lets us publish a hash of your prompt plus the exact output so anyone can verify it. If everyone ran it themselves and pasted results, there would be no way to keep it fair. And our server is locked down: no open public ports, reachable only through a Cloudflare Tunnel.
How are entries judged?
The judging criteria aren’t completely defined yet, but
 
creativity, depth, aesthetics, and functionality
 are some of the things that will be considered. A jury of AI leaders picks 5 of the 6 winners; the 6th is the community favorite, decided by your likes.
Can I use images, 3D models, or fonts?
Yes. Your entry runs in a locked-down sandbox, but it can pull libraries, fonts, and open assets from an allowlist, including CC0 textures and models from Poly Haven. The trick: the model can’t browse, so paste the asset’s exact URL into your prompt. Full guide with examples:
 
how to load assets from the CDNs
.
Do you add anything to my prompt?
One system message, and it is the same for everyone. It only tells the model the output format: a single self-contained HTML file that runs in our sandbox. No creative or quality hints, so the ideas are all yours. You can read the exact text right on the
 
submit form
 and on the
 
architecture page
.
Will there be more rounds?
Yes. This is the first round, and every round after brings bigger prizes. Leave your email and we'll tell you the moment the next one opens.
What can I build?
One self-contained HTML file. You can pull in libraries like three.js from approved CDNs, but there is no build step and no backend. Think games, toys, simulations, generative art, 3D worlds. Anything that runs in a single page.
Why only one file, no backend?
So every entry is instantly runnable, easy to verify, and safe to sandbox in an isolated frame. One file in, one file out. It also keeps the field even: everyone ships the same shape of thing.
What does “one shot” actually mean?
Your prompt is sent to the model a single time. No edits, no retries, no follow-up messages. Whatever it returns, polished or broken, is your entry. You get one shot per day.
When are the prompts and models revealed?
Not until the results. During the round every entry's prompt and model stay sealed, so nobody copies and the model stays a mystery. Each entry still ships with a hash of the prompt and output, so anyone can verify it really was one shot.
