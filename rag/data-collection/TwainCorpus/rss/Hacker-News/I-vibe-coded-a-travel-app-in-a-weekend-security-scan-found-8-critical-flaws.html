TripNest

A role-based group travel planner — plan trips, assign permissions, and keep everything (itinerary, flights, packing lists, chat) in one place instead of scattered across Notes apps and group chats.

🔗 Live app: https://trip-together-planner-21.lovable.app/

Built in a weekend with Lovable, then security-tested with Perfai Security before release.

Why

Group trip planning usually falls apart the same way every time:

  • Itineraries end up in one person's Notes app
  • Flight info gets shared as screenshots buried in a group chat
  • There's no safe way to let people view the plan without risking someone accidentally editing or deleting something
  • Trip discussion gets lost in unrelated chat noise

TripNest solves this with a proper role system and one dedicated space per trip.

Roles

Role Permissions
Admin Full control — add/remove participants and planners, edit everything
Planner Can build out the itinerary, can't remove other travelers
Participant View-only — follows the plan, can't change dates or delete flights

Features

  • Trip creation (name, location, start/end date)
  • Role-based invites with accept-before-join
  • Collaborative day-by-day itinerary planning
  • Location tracking
  • Flight info storage
  • Packing lists (item + quantity)
  • Per-trip group messaging thread
  • Responsive UI

Tech Stack

  • Frontend: React + TypeScript, Tailwind CSS
  • Backend: Supabase (Auth + PostgreSQL)
  • Integrations: Google Maps, OpenWeather
  • Build tool: Lovable
  • Security testing: Perfai Security

Security

The initial deployment was scanned with Perfai Security (tests the live deployed app — routes, roles, and requests — rather than just reviewing source code). The first scan surfaced 8 critical authorization issues that weren't visible from normal UI use. All were fixed and confirmed resolved on a follow-up scan.

If you're building on top of this or forking it, do not treat "it works in the UI" as proof the permission model is enforced correctly at the data layer — verify role restrictions hold across every table/endpoint, not just the components that reference them.

Getting Started

git clone <repo-url>
cd tripnest
npm install

Set up environment variables for Supabase and any map/weather API keys (see .env.example).

npm run dev

Known Limitations

  • Inviting users without a TripNest account currently uses a copy-link share flow rather than email invites (email invites require a custom domain)
