What makes Verso different
Comments
Select text and add a comment. Resolve when done. The sidebar lists every comment with its resolved state. Round-trips through .docx.
Markdown round-trip
Open .md files, edit as rich text with syntax-highlighted code blocks, save back as Markdown. Headings, lists, tables, and formatting all preserved.
Syntax highlighting
22 languages including Swift, Python, TypeScript, Rust, and Go. Paste code into your document and it highlights automatically. Works in both light and dark mode.
