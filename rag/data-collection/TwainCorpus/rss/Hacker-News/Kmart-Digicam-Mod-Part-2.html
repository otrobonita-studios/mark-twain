Ok, so last week the 'c mount lens' I got on ebay for $20 came. So actually it is a lens for a super 8 projector lens. So I had to completely redesign the adaptor. The new one looks like this, it has a much larger diameter as the thread on the lens is 32mm in diameter. Also the thread itself is a really weird custom thread?, mine only fits because I've worn it down from what I originally printed.

But, it does fit, and it does focus light. It just doesn't infinity focus. This needs to be fixed by moving the focus plane closer to the sensor. The only problem is that it is already pressed as closed as it can go up against the existing chassis of the digicam. So on my todo list for this is probably to find a way to physically move the sensor closer to the lens. I tried some paper shims on the sensor board but I didn't see any proper change in focusing from that.
