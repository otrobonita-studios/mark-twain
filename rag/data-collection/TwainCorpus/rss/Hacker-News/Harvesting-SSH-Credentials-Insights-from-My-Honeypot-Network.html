Servers Management and Automation #

  • Ubuntu Server 24.04 LTS or 26.04 LTS
  • Automation with Ansible
  • Onboarding
    • User creation
    • Installation required software
    • Basic config
  • Wireguard VPN Setup
    • Config for connection to central management server
    • FW rules
  • SSH Setup
    • SSHD listening only on VPN IP and Port 2222 (to avoid any conflicts)
    • the usual hardening (public key, etc)
  • Honeypot Setup
    • Runs as a rootless Podman container (Systemd service via Quadlet)
    • Port 22 as non-root with net.ipv4.ip_unprivileged_port
