Step 3 â Understand what happened
The example did three things:
Built a model
 â a standard MathOpt 
Model
 with variables, an objective,
and (in the MILP) constraints. Nothing in it is Quicopt-specific; the same
code runs against any MathOpt-compatible solver, and a Pyomo model works the

Called

 â the client converted the model, sent it to

Printed and returned the result

server renders; the

API reference
