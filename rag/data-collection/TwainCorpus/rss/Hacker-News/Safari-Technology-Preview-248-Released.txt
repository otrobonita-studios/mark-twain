Release Notes for Safari Technology Preview 248

Jul 22, 2026

by 
Jon Davis

Safari Technology Preview
 Release 248 is now 
available for download
 for macOS Golden Gate and macOS Tahoe. If you already have Safari Technology Preview installed, you can update it in System Settings under General → Software Update.

This release includes WebKit changes between: 
315567@main…316817@main
.
